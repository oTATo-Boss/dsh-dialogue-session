# Third-party components

This distribution includes the JavaScript runtime of [dsh-memory](https://github.com/haitang1/dsh-memory/tree/15de1c791bbcb5be2c9b0c2096eddedcaa61cc17) 0.5.0 with local changes to model routing, structured extraction, per-session cursors, cancellation and recovery. [MIT license](vendor/memory/LICENSE).

The runtime of [dsh-context-reminder](https://github.com/xuan25/dsh-context-reminder/tree/8d6674e135c30e8e5be4d74af4abc7479581e3dc) 0.1.0 is distributed as JavaScript generated from its TypeScript sources. [MIT license](vendor/reminder/LICENSE).
